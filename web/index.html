How it works

The Go server runs only on 127.0.0.1. The generated dashboard is a standalone HTML file for exploring the graph, adjusting the target, excluding branches and exporting PGN/PNG/CSV.

The selected side controls score, trap detection and which moves are repertoire choices. Positive engine evaluations always favor White.

Lichess rating bands are not FIDE Elo ratings.
